# Carmem Avila Arquitetura — Home

Reformulação da página inicial do site [carmemavila.com.br](https://www.carmemavila.com.br/),
com direção editorial minimalista (Montserrat Light/Medium, muito espaço em branco).

## Arquivos

- **`index.html`** — home de produção (responsiva, com animações de scroll)
- **`index-figma.html`** — frame Desktop 1440 estático, para importação no Figma
- **`assets/`** — logo, retrato e imagens dos projetos

## Rodar localmente

```bash
python3 -m http.server 8000
```

Depois abra `http://localhost:8000`.
